מערכת הניהול של כשר פליי

בהפעלה הראשונה בלבד, הזן את שם מאגר GitHub שבו האתר שמור.

לדוגמה, אם כתובת המאגר היא github.com/moshe/kosher-fly, יש לכתוב: moshe/kosher-fly
הערך נשמר בדפדפן הזה. לשינוי מאוחר יותר פתח /admin/?setup=1

לפני הכניסה הראשונה יש לבצע את שלבי GitHub + Netlify OAuth שמופיעים בקובץ ההדרכה המצורף.
